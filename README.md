# 🚀 Portafolio de Desarrollo Web - Nivel 3

Bienvenido a este repositorio. Aquí encontrarás la colección de desafíos y el proyecto final desarrollados durante mi cursada de Desarrollo Web Frontend Avanzado.

## 📂 Contenido del Repositorio

Este repositorio está organizado en carpetas correspondientes a las entregas clave:

* **Desafío 1:** Fundamentos y lógica inicial con JavaScript.
* **Desafío 4 (Clase 4 App):** Implementación de **React** con **Vite**. Uso de componentes y manejo de estado.
* **Proyecto Final (E-commerce):** Una aplicación SPA (Single Page Application) simulando un e-commerce (Mercado Libre clone).

## 🛠️ Tecnologías Utilizadas

El stack tecnológico principal de estos proyectos incluye:

* **Frontend:** React.js (v18)
* **Build Tool:** Vite
* **Lenguajes:** JavaScript (ES6+), HTML5, CSS3
* **Estilos:** Bootstrap 5 / Bootswatch
* **Routing:** React Router Dom
* **Manejo de Datos:** Context API, Fetch a APIs simuladas (MockAPI/JSONPlaceholder)


## 🌟 Funcionalidades Destacadas

* **Navegación:** Sistema de rutas funcional para ver Home, Detalles de Producto y Categorías.
* **Consumo de API:** Los productos se cargan dinámicamente desde una API externa.
* **Gestión de Estado:** Uso de `useContext` para manejar el estado global de los productos y el carrito.
